🎯 Key Architecture Principles for Extensibility

  1. Common Interface: All integration services implement NodeExecutor interface
  2. Auto-Registration: Spring Boot discovers and registers services automatically
  3. Event-Driven: Kafka enables async, scalable workflow execution
  4. Stateless Services: Each service is independent and horizontally scalable
  5. JSON Workflow Definition: Workflows stored as graphs in PostgreSQL
  6. Docker Everything: Each service runs in its own container for easy deployment
